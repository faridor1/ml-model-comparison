# Regression dataset

The notebook expects the following files in this directory:

| File | Purpose |
|---|---|
| `train_X.csv` | Training features |
| `train_y.csv` | Training target |
| `test_X.csv` | Unlabeled test features |

The notebook reads these CSVs using `index_col=0`. Keep the original column names and index structure intact.
